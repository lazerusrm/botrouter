# Changelog

- Corrected the public CI help smoke test to validate the CLI's actual stable heading.
- Included every runtime module required by host recovery in the npm package.

## 0.1.1 - 2026-09-01

- Made host recovery install the prompt, Computer, and Auto-review modules as one validated bundle so the watchdog cannot restore stale routing code after restart.

- Initial BotRouter release.
- Added Codex, Grok, Cursor subscription, and automatic model routing controls.
- Added direct browser DOM, Computer, native search, and dynamic-tool support.
- Added hidden transient-provider retries and continuation safeguards.
- Added a restart-resumable setup plugin, runtime doctor, SSH prerequisite check, and masked secret-store guidance.
